# Memory: completed work

One line per finished item of [memory-implementation-plan.md](memory-implementation-plan.md).

- [x] Buffer is a userspace construct over Frames; no kernel Buffer kind.
- [x] Device Frames: Retype carves Frames from a device Untyped without zeroing them, and `Frame.Map` installs them as Device-nGnRnE memory, never executable (nucleus `untyped` and `page_table` tests).
- [x] `EXECUTE` mappings are executable at exactly one level (PXN/UXN), never RW+X at EL0.
- [x] Explicit PageTable installation (`PageTable.Map`/`Unmap`); `Frame.Map`/`Unmap`/`GetAddress` with an explicit target AddressSpace, rights ceiling, W^X at one exception level and recorded mapping identity; Copy installs no mapping.
- [x] No intra-AddressSpace physical aliases (`PhysicalAlias`); cross-AddressSpace aliases allowed.
- [x] ASID pool allocation, `ASIDPool.Assign`, ASID-scoped TLB invalidation on unmap, `AddressSpace.Activate` installing the root, non-global TTBR0 leaves (`test-memory`).
- [x] Frame cache maintenance: CleanData `3`, InvalidateData `4`, CleanInvalidateData `5`, UnifyInstruction `6` over a byte range through the kernel direct map (`FrameKey::clean_data` and siblings, `ArchObjects::maintain_cache`); ABI and wrapper encoding in `just _test-object-host`, operations, ranges, rights and device refusal in `just _test-memory`.
- [x] Frame memory attributes ([MEMORY-4](memory-design.md#memory-4-frame-memory-attributes)): `FrameAttribute` (`libs/object/src/frame.rs`) names `Frame.Map`'s `x5` codes and orders the four attributes; ceilings sit on device Untypeds and Frames (`RegionPayload::ceiling`, `FramePayload::ceiling`), are set by Kickstart (video memory `WriteCombining`, registers `DeviceStrict`), lowered at Retype through `x3` bits 15:8 (`UntypedKey::retype_with_ceiling`), inherited by split children and `CopyDerive`, and checked by `Frame.Map` (RAM maps `Cacheable` only). `MAIR_EL1` is programmed by Kickstart with typed fields: 0 write-back, 1 write-combining, 2 Device-nGnRE, 3 Device-nGnRnE (`kernel/kickstart/src/el_switch.rs`, shared by the nucleus descriptors, Kickstart's mappings and `libmemory`). fb carves the framebuffer Frames with a `WriteCombining` ceiling and the shell maps them write-combining. Exercised by `frame_attribute_ceilings` in `kernel/tests/memory-test` (descriptor `AttrIndx`, refusals, lowering, inheritance, RAM), `libs/object/tests` (wire codes, ordering) and `just _test-shell`.
- [x] Boot Untyped in the first gigabyte ([MEMORY-1](memory-design.md#memory-1-ram-untypeds-and-reach)): `BootInfo::alloc_region_below` places it as high under 1 GiB as fits, the old placement as fallback; the mailbox refuses a bounce page beyond 32 bits; the Pi 5's mailbox and `sdhci` ADMA2 work on the board.
