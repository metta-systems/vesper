Engine code (room::engine, room::headless, room::types) that needs more than
core + alloc, i.e. what stops the engine building for Vesper.

Scope: everything outside src/platform/, skipping #[cfg(test)] code.
Found by searching the source for std-only paths and
macros, and for calls to C library functions; a call made through a local
alias or a function pointer would not show up.

Format: file: function: what it uses.

the libc crate.
