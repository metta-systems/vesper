# SC55Soundfont

The Roland SC-55 SoundFont that we've all been waiting for. With the help of Kitrinx's and NewRisingSun's SC-55 to SoundFont converter.

Installation:
Download the soundfont and just throw the .sf2 file into your soft synth, whether it is VirtualMIDISynth or Fluidsynth.
